# AURELLE — The Floating Isles

A vintage sunset travel poster for a place that isn't there, drawn by a
deterministic Python + Pillow program. Entry for
[The Poster for a Place That Isn't There](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539)
on make.fun.

## The place

AURELLE is an archipelago drifting above a sea of clouds. Its lighthouse
island spills waterfalls off its edges into the cloud sea below; a second
pine-topped isle keeps it company; coral airships run daily, and the sun
never quite sets — sunset season, 19° all year.

## Run it

```sh
python3 main.py   # writes /output/entry.png (1024x1024 PNG)
```

Stdlib + Pillow only, no network, seeded deterministic RNG — two runs
produce byte-identical output.
